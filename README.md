# NumPy-Image-Processor


A beginner-friendly image processing project built with **Python, NumPy, and Pillow**.

This project demonstrates how images can be loaded and manipulated as **NumPy arrays**. It was built to practice NumPy fundamentals through a practical project.

## 🚀 Features

* Load images using Pillow
* Convert images into NumPy arrays
* Display images
* Convert RGB images to grayscale
* Adjust image brightness
* Flip images horizontally and vertically

## 🛠️ Technologies Used

* **Python**
* **NumPy**
* **Pillow (PIL)**

## 📁 Project Structure

```text
numpy-image-processor/
│
├── main.py
├── image_processor.py
├── requirements.txt
├── README.md
│
└── images/
    └── image.jpg
```

## ⚙️ Installation

Clone the repository:

```bash
git clone <your-repository-url>
cd numpy-image-processor
```

Install the required libraries:

```bash
pip install -r requirements.txt
```

## ▶️ How to Run

Make sure an image is placed inside the `images` folder.

Then run:

```bash
python main.py
```
